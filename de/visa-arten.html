Visa A, C, D — welches brauchen Sie?

Drei Buchstaben, drei sehr unterschiedliche Visa. Eine fundierte Wahl beginnt damit, klar zu verstehen, was jeder Typ erlaubt — und was nicht.

Visum A — Flughafentransitvisum

Verpflichtend für Staatsangehörige einer begrenzten Liste von Ländern (Anhang IV des Visakodex), die durch einen Schengen-Flughafen reisen, ohne den internationalen Bereich zu verlassen. Manche Mitgliedstaaten verlangen ein Visum A auch für Staatsangehörige nicht aufgeführter Länder, abhängig von der Migrationssituation.

Detaillierte Anleitung: Flughafentransitvisum →

Visum C — Kurzaufenthalt

Das Visum, das die meisten Reisenden meinen, wenn sie „Schengen-Visum" sagen. Erlaubt Tourismus, Geschäftsreisen, Familienbesuche, kurze Studien, kulturelle Veranstaltungen oder medizinische Behandlung. Strenge 90/180-Regel: Sie können in einem rollierenden 180-Tage-Zeitraum nicht mehr als 90 Tage anwesend sein.

Es gibt mehrere Untertypen: einfache Einreise, doppelte Einreise, Mehrfacheinreise (1, 3 oder 5 Jahre) — die Kaskadenregeln belohnen wiederkehrende Reisende mit guter Reisehistorie.

Detaillierte Anleitung: Kurzaufenthaltsvisum C →

Visum D — Nationaler Langzeitaufenthalt

Erforderlich für jeden Aufenthalt von mehr als 90 Tagen: Studium, Arbeit, Praktika, Familienzusammenführung, Forschung, Ruhestand. Im Gegensatz zum Visum C wird das Visum D nach den Gesetzen jedes einzelnen Mitgliedstaats erteilt — Anforderungen, Gebühren und Bearbeitungszeit variieren stark.

Wichtig: Mit einem Visum D, das von einem Schengen-Land ausgestellt wurde, können Sie auch in andere Mitgliedstaaten für Kurzaufenthalte unter 90 Tagen reisen. Das vereinfacht zum Beispiel das Leben für einen Studenten in Deutschland, der ein Wochenende in Wien verbringen möchte.

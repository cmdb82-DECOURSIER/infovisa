Nous contacter

Nous répondons aux questions générales sur les procédures Schengen. Pour les décisions et votre cas particulier, seul le consulat est compétent.

ℹ️ Important : ce guide est informatif. Confirmez toujours auprès du consulat officiel avant d'introduire votre demande. Les règles peuvent évoluer rapidement.
InfoVisa.lu n'est pas un organisme gouvernemental. Nous ne traitons pas les demandes, ne prenons pas de rendez-vous, et n'avons aucune influence sur les décisions consulaires. Pour votre dossier, contactez le consulat du pays de destination.

Comment pouvons-nous aider ?

Nous répondons aux questions générales :

  • Quel type de visa pour votre voyage ;
  • Documents et procédures standards ;
  • Frais, délais, ETIAS, EES ;
  • Où trouver l'information officielle.

Nous ne pouvons pas :

  • prendre votre rendez-vous ;
  • déposer des documents pour vous ;
  • prédire l'issue de votre demande ;
  • contacter un consulat pour vous ;
  • donner un avis juridique sur un cas particulier.

Email

Écrivez-nous : contact@infovisa.lu. Mentionnez :

  • Votre nationalité ;
  • Votre pays de résidence ;
  • Le pays de destination ;
  • Le type de visa (C / D) ;
  • Dates et objet du voyage.

Délai moyen de réponse : 2 à 3 jours ouvrés.
